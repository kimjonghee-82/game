    카메라 번역

    저장된 번역

      설정

      아래 값들은 이 브라우저에만(localStorage) 저장되며, 깃허브 저장소에는 절대 올라가지 않습니다.

      사진 분석용 Groq API 키

      사진을 AI 비전 모델이 직접 보고 상호/장소/영수증 정보를 정리하거나(일정·비용·투어 정보) 사진 속 외국어를 한국어로 번역하는 데(카메라 번역) 사용됩니다. console.groq.com에서 발급받으세요. Groq API는 완전 무료이며 카드 등록이 필요 없습니다. (미입력 시 또는 분석 실패 시 사진의 촬영시간·GPS 위치만 자동 인식됩니다)

      카메라 번역 원본 언어

      화면 위에 항상 떠 있는 카메라 아이콘으로 사진을 찍으면, 아래 언어로 된 글자를 읽어서 한국어로 번역합니다.

      구글 시트 연동 (OAuth 클라이언트 ID)

      Google Cloud Console에서 발급받은 OAuth 2.0 클라이언트 ID(웹 애플리케이션)를 입력하세요. 발급 방법은 채팅 안내를 참고하세요.

      실시간 동기화 (트립 코드)

      일정·비용·투어 정보·기타(영상)를 다른 기기와 실시간으로 자동 동기화합니다. 아무것도 입력하지 않으면 기본 코드로 자동 연결되어 별도 설정 없이 PC/모바일 간 동기화됩니다. 우리끼리만 쓰고 싶다면 원하는 코드를 만들어서 모든 기기에 똑같이 입력하세요. 동기화 켜지기 전에 이미 저장해둔 데이터가 있다면(예: 예전에 PC에서 올린 영상), 아래 버튼을 한 번 눌러 지금 이 기기 데이터를 클라우드에 올려주세요 — 그래야 다른 기기에도 나타납니다.

      다른 기기와 설정 공유

      API 키를 포함한 현재 설정을 코드로 만들어서, 다른 기기의 설정 화면에 붙여넣으면 그대로 복사됩니다. 이 코드 안에 API 키가 그대로 들어있으니 본인만 아는 안전한 곳(메모앱 등)에 보관하세요 — 깃허브에는 올라가지 않습니다.
